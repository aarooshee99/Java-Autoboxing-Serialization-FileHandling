# Java-Autoboxing-Serialization-FileHandling
Java Experiment 2.2 demonstrating Autoboxing, Unboxing, Object Serialization, and File Handling. Includes programs to sum integers using autoboxing, serialize and deserialize Student objects, and manage Employee records through a menu-based file system.
